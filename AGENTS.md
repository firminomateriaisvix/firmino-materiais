# Instruções de manutenção

Este projeto é exclusivamente da Firmino Materiais V2. Preserve informações confirmadas da empresa e não acrescente dados comerciais sem fonte. Leia README.md e docs/PUBLICACAO.md antes de editar ou publicar. O site estático é compilado por `pnpm build:static`; a saída é dist/public. Mantenha contatos e domínio indicados nos documentos. O remote origin é referência do site original: não enviar alterações para ele sem autorização. Não adicionar credenciais, dados pessoais de cadastro, arquivos de QA ou logs ao Git.
